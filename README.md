# Mint-Dark theme for Stremio Enhanced

A dark theme for Stremio Enhanced inspired by Linux Mint's Mint-Y-Dark color scheme, bringing a familiar grey-ish look to the Stremio Enhanced interface.

## Installation

  There are two ways to install the Countdown Timer plugin:
  
1. Via Stremio Enhanced Marketplace (Recommended)
    - Open the Stremio Enhanced Community Marketplace (Settings → Scroll to the bottom)
    - Search for Mint Dark
    - Click Install
    - Enable it and restart Stremio to apply changes.

2. Manual Installation
    - Download mint-dark.theme.css from the latest release.
    - Drag and drop it into your local Stremio Enhanced themes folder.
    - Enable it and restart Stremio to apply changes.
